# Shortcuts

Makes the Map and Versus buttons a little more useful! Hope you will like it! Here's what the mod does:

The mod gives the Map and Versus buttons a new purpose by changing their appearance and functionality.

## Versus

When you click the Versus button, the will no longer say "Versus mode is delayed". Instead, it will open the Globed menu. Why? Because Globed is multiplayer, and the Versus button is meant to be related to multiplayer. (The Globed mod is REQUIRED for the mod work)

## The Map

When you click the Map button, the "Coming in 2.21" message will no longer appear. Instead, it will take you to The Tower. Why? Simply because The Tower is platformer, and the Map button is meant to be related to platformer content.
